Long output: replies up to 128K tokens

Four task types with machine checks: multi-file Python projects with hidden tests, MATH-500 level-5 problems, 10,000-12,000-word essays, and product catalogues as JSON. Each stage raises the output cap; L3s repeats one prompt per type one request at a time.
