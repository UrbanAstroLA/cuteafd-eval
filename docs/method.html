Method: how the results are made and how to weigh them

Every result on this site is a finding: one measured quantity, with its sign convention, unit, sample size, interval, scope and the file it was read from. Findings were written from the published data of each run, and the build refuses any number that does not trace to that data. Judgements across runs are separate entries, each with a strength (established, supported, indicated or open) set by a fixed rule, the findings it rests on, and the nearest stronger claim it does not support. Comparison rules were frozen before the data in every run that had a protocol; anything decided after looking is labelled post hoc or exploratory wherever it appears.

The standard every finding meets

FieldWhat it holds
quantity, signwhat was measured and which way is up, with the difference named (b − a)
unit, nthe unit of analysis (window, item, question, prompt, document, cell) and how many
intervallevel and method: bootstrap over which unit, how many replicates, which seed; or none (descriptive)
scopeengine and version, checkpoint, item set, context range, path (prefill or generation), hardware
statusprotocol, amendment, follow-up, post hoc, exploratory, check, source reading, accounting
familyhow many intervals were computed alongside it in the same table, and how many excluded 0
replicationreplicated, failed to replicate (with a link), or not attempted
classdifference (interval excludes 0) · not detected (interval includes 0; the largest effect not excluded is stated) · descriptive (counts, no interval) · source reading · accounting

Wording follows the class. An interval that includes 0 is written as "not detected; a cost up to X is not excluded", never as "no difference". A result found on one item set is not generalised past it. A lead that failed to replicate stays published beside the replication, and each links to the other. Intervals are reported as computed; they are not corrected for multiplicity unless a protocol said so, and the family size beside each one says how many were computed.

How strong a judgement is

The strength vocabulary is defined on the terms page. A judgement is never stronger than its weakest essential finding, and each states what it does not show.
